# ALCHA Website

Official website for **ALCHA LLC**.

This repository hosts the public-facing ALCHA website and is intended to be deployed with GitHub Pages at **https://alcha.app**.

## About ALCHA

ALCHA builds simple, thoughtful digital products designed to make everyday life a little easier.

## Site structure

- `index.html` — main landing page

## Deployment

This site is designed for GitHub Pages.

1. Open **Settings → Pages** in this repository.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select the `main` branch and `/(root)` folder.
4. Save.
5. After the GitHub Pages URL is live, add `alcha.app` as the custom domain.
